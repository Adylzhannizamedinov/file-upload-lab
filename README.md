# Практическая работа №12 — Загрузка файлов в веб-приложение

**Вариант:** 1 — Фотогалерея путешествий (подпись и место)

## Описание

Веб-приложение для хранения фотографий из путешествий.

- загрузка одного или нескольких (до 5) изображений за раз;
- проверка типа (JPG / PNG / WEBP) и размера (до 2 МБ) **на клиенте и на сервере**;
- предпросмотр перед отправкой, имя и размер файла в КБ;
- прогресс-бар загрузки (XMLHttpRequest);
- дополнительные поля формы «Подпись» и «Место» (FormData → `req.body`);
- метаданные в `server/files.json`, сами файлы — в `server/uploads`;
- галерея, обновляющаяся без перезагрузки страницы;
- удаление фотографий (файл и запись в JSON).

**Стек:** Node.js, Express, Multer, React (Vite).

## Запуск

Нужен Node.js 18+. Два терминала:

```bash
# 1. Сервер  (http://localhost:3000)
cd server
npm install
npm start

# 2. Клиент  (http://localhost:5173)
cd client
npm install
npm run dev
```

Откройте http://localhost:5173.

## API

| Метод  | Маршрут           | Описание                                        |
|--------|-------------------|-------------------------------------------------|
| POST   | `/api/upload`     | form-data: `files` (до 5), `title`, `place`     |
| GET    | `/api/files`      | список метаданных                               |
| DELETE | `/api/files/:id`  | удалить файл и запись                           |
| GET    | `/uploads/<имя>`  | статическая раздача изображений                 |

Проверка в Postman: POST `http://localhost:3000/api/upload`, Body → form-data, ключ `files` (тип File).

## Ответы на контрольные вопросы

1. **multipart/form-data vs JSON.** JSON — только текст. multipart делит тело запроса на части с границей (boundary); каждая часть — поле формы, текстовое или двоичный файл.
2. **Почему не задавать Content-Type вручную у FormData.** Браузер сам добавляет `multipart/form-data; boundary=...`. Если указать заголовок вручную, границы не будет, и сервер не разберёт тело.
3. **express.static.** Делает папку доступной по URL, чтобы браузер мог получить файлы (`<img src="/uploads/...">`).
4. **Проверка на сервере.** Проверку в React можно обойти (Postman, curl, правка кода в браузере). Серверная проверка — единственная настоящая защита.
